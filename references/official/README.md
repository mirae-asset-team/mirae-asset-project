# 공식 자료

공모전 주최 측과 네이버클라우드가 배포한 원문을 보관합니다.

- `competition/과제소개자료_공시Agent.pdf`: 공시 Agent 공식 과제소개 자료
- `ncp/네이버클라우드_서비스소개.pdf`: NCP와 CLOVA Studio 이용 안내
- `ncp/네이버클라우드_크레딧지급가이드.pdf`: 크레딧 신청·등록 안내
- `source_archives/`: 내려받은 원본 압축 파일. 대용량이므로 Git 추적에서 제외
- `SHA256SUMS.txt`: 보관한 공식 PDF의 무결성 값

공식 과제소개 자료에서 확인된 하드 제약은 다음과 같습니다.

1. 평가용 LLM은 HyperCLOVA X만 사용할 수 있습니다.
2. 주최 측 제공 코퍼스 외 데이터는 답변 생성에 사용할 수 없습니다.
3. OpenDART 등 외부 공시 API의 실시간 호출은 금지됩니다.
4. 모든 답변은 근거 공시를 표시해야 하며, 확인할 수 없는 내용은 그 한계를 밝혀야 합니다.
