# 기술제안서 설계

## 산출물

- 저장소 내 한국어 원고 Markdown
- 제출 가능한 한국어 PDF
- 자유 양식이지만 공식 과제자료의 필수 제안 항목을 빠짐없이 포함

## 구조

1. 제안 요약과 문제 정의
2. 핵심 설계 원칙: 시간·정정·단위·근거를 보존하는 공시 전용 Agent
3. 시스템 구성도와 처리 흐름
4. 주요 기능과 사용자 시나리오
5. 데이터 범위와 외부 데이터 차단
6. HyperCLOVA X의 제한된 역할과 검증 계층
7. 측정 결과: 데이터 규모, 회귀, deterministic 300, 지연, 안전성
8. API·웹 시연 및 재현 방법
9. 한계와 미완료 외부 게이트
10. 기대효과·확장성·운영 계획

## 진실성 규칙

- deterministic 300/300을 HyperCLOVA X 300/300으로 표현하지 않는다.
- 현재 공개 서버가 API-only이며 새 웹 UI 배포는 차단됐음을 숨기지 않는다.
- Recall@20 약 0.765와 provider 미검증을 한계로 제시한다.
- DB/overlay/index의 read-only와 출처 귀속을 핵심 안전장치로 설명한다.
- 비밀값, 공인 IP, 질문 원문 묶음, 내부 경로를 PDF에 넣지 않는다.
