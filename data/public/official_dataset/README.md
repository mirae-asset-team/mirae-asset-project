# 주최 측 공식 공시 데이터셋

2026 미래에셋증권 AI Festival 공시 Agent 과제를 위해 주최 측이 제공한 데이터입니다.

## 위치

- `source_archives/`: 다운로드 원본 ZIP과 내부 `3.공시.zip`; Git 추적 제외
- `raw/corpus/`: 안전하게 전개한 원본 코퍼스; Git 추적 제외
- `raw/corpus/README.md`: 주최 측 데이터 설명 정본
- `raw/corpus/data_filter.md`: 기업·문서유형·기간 선정 조건
- `raw/corpus/universe.csv`: 70개사 기업 마스터
- `raw/corpus/manifest.jsonl`: 4,204개 문서 메타데이터
- `raw/corpus/raw/`: 공시 원문
- `SHA256SUMS.txt`: 다운로드 원본 압축파일 무결성 값

## 검수 결과

| 항목 | 확인값 |
|---|---:|
| 대상 기업 | 70개사 |
| 대상 기간 | 2023-01-01~2026-03-31 |
| 문서 | 4,204건 |
| 원문 XML | 4,616개 |
| 정정공시 | 1,004건 |
| 전개 파일 | 4,907개 |
| 전개 용량 | 5,567,999,349 bytes |

문서 유형은 정기공시 1,054건, 주요사항보고서 598건, 거래소공시 1,469건, 지분공시 1,083건입니다. XML 원본이 제공되지 않은 3건은 공식 PDF와 공시뷰어 HTML로 대체되어 있습니다.

## 불변 원칙

- `raw/` 아래 원본은 수정하지 않습니다.
- `corp_code`와 `stock_code`는 선행 0을 보존하는 문자열로 읽습니다.
- 가공 결과는 `data/derived/`에 만들고, 사용한 `doc_id`, `rcept_no`, 원본 해시와 변환기 버전을 기록합니다.
- `is_correction`만으로 최신 유효본을 단정하지 않습니다. 원본·정정 관계와 질의 기준시점을 별도로 모델링합니다.
- 외부 자료는 연구에만 사용하며 평가 답변의 검색 인덱스에는 넣지 않습니다.
